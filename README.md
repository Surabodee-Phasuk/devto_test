# Dev.to Test Project

โปรเจกต์นี้จัดทำขึ้นเพื่อการทดสอบ พัฒนา และเรียนรู้การใช้งาน React รวมถึงโครงสร้างเว็บพื้นฐาน โดยมีการแบ่งขั้นตอนการพัฒนาออกเป็นส่วนๆ (Parts) เพื่อความง่ายในการติดตามผลและการจัดการโค้ด

---

## 📁 โครงสร้างโปรเจกต์

ภายใน Repository นี้ประกอบไปด้วย:

* **Part1, Part5, Part6**: โฟลเดอร์เก็บโค้ดแยกตามขั้นตอนการเรียนรู้หรือการพัฒนาฟีเจอร์ต่างๆ
* **react-app-project**: โปรเจกต์หลักที่พัฒนาด้วย React.js
* **Root Files**: ประกอบด้วย `index.html` และ `app.css` สำหรับการทดสอบพื้นฐาน

## 🚀 เทคโนโลยีที่ใช้

* **React.js** - สำหรับสร้าง User Interface
* **HTML5 / CSS3** - สำหรับโครงสร้างและหน้าตาของเว็บไซต์
* **JavaScript (ES6+)** - สำหรับการทำงานในส่วน Logic
